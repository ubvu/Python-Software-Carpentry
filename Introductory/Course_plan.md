# Intro

The course is always being adapted, changed, and updated based on feedback and trial and error. Over time the course will have deviated enough from the original content of the carpentries that we will have to submit it as a new course.

# The Plan

As of September 2026, we intend to change the course order to the following:

    -   data types
    -   basic maths
    -   import custom library
    -   lists
    -   slicing
    -   plot lists
    -   conditionals
    -   plot conditionals
    -   pandas
    -   loops
    -   loop plots
    -   functions 
    -   plot function output
    -   errors
    -   debugging
    -   practice project
    -   own project

We felt that including visual output at every stage should ensure that we cover multiple learning styles at once, listening, doing, and seeing. It is also always nice when you have something to see and share at the end of working/studying.

Lists needs to come before pandas as we can introduce indexing and slicnig at once before showing the more complex 2D tables and two methods of indexing. Conditionals are also a concept best to introduce before the dataframes so that we can show conditional filtering of dataframes and masking with context of what a boolean is.
